# NodeKart

NodeKart is Decentralized marketplace  powered by protected SHARP Payments It is secure And Encrypted Platform.

## Run locally

```bash
npm install
npm run dev
```

The prototype uses local mock data and simulated wallet, escrow, settlement, and cashback events. Start at the marketplace, open a product, complete checkout, then use the demo order controls to move from shipment to delivery confirmation and cashback.
